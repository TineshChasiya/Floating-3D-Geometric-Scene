# 🌌 Floating 3D Geometric Scene

A futuristic interactive 3D scene built using **HTML, CSS, and Vanilla JavaScript**. It features a rotating 3D cube, pyramid, orbit ring, floating particles, mouse interaction, and scroll-based depth effects.

## ✨ Features

- 🧊 Interactive 3D rotating cube
- 🔺 Animated 3D pyramid
- 🌀 Glowing orbital ring
- ✨ Floating particle background
- 🖱️ Mouse-based 3D interaction
- 📜 Scroll-based depth shift
- 🌌 Dark futuristic UI
- 💡 Radial background glow
- ⚡ Smooth `requestAnimationFrame()` animations
- 📱 Works across different screen sizes
- 🚫 No external libraries or frameworks

## 🛠️ Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- HTML5 Canvas
- CSS 3D Transforms
- CSS Animations

## 🚀 How to Run

### Option 1 — Directly Open

1. Download or clone the repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The project will open in your browser.

### Option 2 — VS Code

1. Open the project in Visual Studio Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

## 🎮 Interaction

### Mouse Movement

Move your mouse around the screen to control the 3D scene rotation.

### Scrolling

Scroll down to create a dynamic depth-shift effect with additional 3D rotation and movement.

## 🎨 Main Components

### 3D Cube
Built using CSS 3D transforms with six individual faces and continuous rotation.

### 3D Pyramid
A CSS-based pyramid with animated rotation and scaling effects.

### Orbit Ring
A dashed circular ring creates a futuristic orbital effect around the geometry.

### Particle System
HTML5 Canvas generates and animates floating particles in the background.

### Background Glow
A radial gradient creates a soft futuristic ambient glow behind the scene.

## ⚡ Performance

The project uses `requestAnimationFrame()` for smooth animations and lightweight Canvas rendering.

No external libraries, images, fonts, or frameworks are required.
